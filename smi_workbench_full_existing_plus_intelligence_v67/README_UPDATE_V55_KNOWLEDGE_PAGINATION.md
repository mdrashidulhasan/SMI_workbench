# v55 Knowledge Map pagination update

This update keeps the v54 workflow and Knowledge Map drill-down behavior, but improves output page performance.

Changes:
- Related papers are paginated instead of rendering every paper at once.
- Default paper page size is 100, with 50/100/150/250 options.
- Cluster drill-down still shows papers for the selected cluster, but page by page.
- Added Clear cluster selection and Clear all filters buttons.
- Search, deduplication, AI screening, extraction, PDFs, and Knowledge Space generation logic were not changed.
